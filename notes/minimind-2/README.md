# MiniMind 文档

欢迎来到 **MiniMind** 文档。MiniMind 是一个以极低成本从零训练超小型语言模型的开源项目,仅需约 2 小时和 3 美元即可在单张消费级 GPU 上训练出可用的聊天机器人。
